# website-price-ticket

This website is created using **PHP**, **CSS**, **JavaScript**, and **SQL**.

## Dependencies

- [Bootstrap](https://getbootstrap.com/)
- [SweetAlert2](https://sweetalert2.github.io/recipe-gallery/)

## Features

- Users can:
  - Get tickets
  - Log in and out
  - Register
  - Edit profiles
  - And more...
